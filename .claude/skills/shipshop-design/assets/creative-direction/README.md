# Creative direction - source files

| File | What it is | How to use it |
|---|---|---|
| `palette-study.pdf` | Client palette study; option **E · Boutique Blush** is the chosen palette (palo de rosa `#A4505D`, blush `#F6E4E1`, malva `#7A4E5E`, champán `#C8A66B`, marfil `#FFFCFA`) with contrast checks. | Reference for color values and accessibility. Other options in the file are not in use. |
| `typography-boutique-blush.pdf` | Ten type pairings tested on Boutique Blush + general text-treatment rules. Option **10 · Young Serif + Plus Jakarta Sans** ("Cercana con carácter") is the chosen one. | Use option 10's treatment and the general rules. Ignore the other pairings and the recommendation for option 03; the final guide chose 10. |

The final decisions live in **"Guía Boutique Blush · Tipografía 10"** (Claude Design project). Its palette, tokens, type scale, component list, screens, business rules, WhatsApp templates and data model are transcribed into this skill:
- palette and contrast → `references/brand-foundations.md`
- tokens → `references/tokens.css`
- type scale and treatment → `references/visual-system.md`
- components and data model → `references/components.md`
- screens and Home order → `references/page-blueprints.md`
- microcopy and WhatsApp messages → `references/voice-and-copy.md`

The reference wireframes are "Store Wireframes v2 · option 2b" in the same Claude Design project. If the guide changes, update the files above. Change palette or type values in `tokens.css` only; components reference tokens.

The PDFs mention reference stores used during exploration. They are background material only: never copy their layouts, copy or assets.
